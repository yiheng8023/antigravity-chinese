## 缺陷与修复

旧运行时会在代码、终端和编辑框之外按词典匹配任意 DOM 文本。因此，已发送消息或用户命名的资源恰好包含 `Settings`、`New conversation` 等词条时，也会被显示为中文。

本次使用客户端实际 DOM 结构核对消息与名称边界，不记录会话正文、文件名、路径或账号信息：

- 消息正文：`user-input-step`、`user-message-content`、`planner-response-text`、`data-markdown-root`，以及已支持的 Markdown 容器。
- 文件内容与标识：`role=tree/treeitem`、文件路径导航、同时带有 `data-uri` 和 `data-quotable-inline` 的文件引用。
- 名称：`breadcrumb-segment`、带 `data-project-label` 的 `project-header`、`conversation-row-sidebar` 中的名称和导航链接。

文字节点、可翻译属性和多个文本节点的合并翻译使用同一保护判断。MutationObserver 从深层节点进入时仍检查祖先；节点移动后重新判断上下文，不永久缓存保护状态。

混有固定界面操作的消息或会话行保留自身文字，并继续遍历真正的按钮和状态控件。正文内部的按钮仍属于正文，保持原文；普通设置说明和操作按钮继续翻译。
