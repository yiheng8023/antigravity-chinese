# Antigravity 2.30.0 维护记录

2026-11-10 核对 [官方桌面更新日志](https://antigravity.google/docs/changelog/) 和 [VS Code 扩展日志](https://antigravity.google/docs/changelog?tab=extensions&ide=vscode)。官方 2.30.0 条目日期为 2026-11-09，包含 27 项改进和 25 项修复。Windows x64 本机为 App 2.30.0、VS Code 1.145.2 和 Antigravity 扩展 1.11.0。桌面更新后回到原生 ASAR，扩展仍保留原有汉化。

## 变更影响

| 上游范围 | 本地化处理与验证范围 |
| --- | --- |
| 知识工作布局、首页引导、设置与无障碍 | 补充布局选项及说明、首页问候语、首登工作类型问题、终端位置和屏幕阅读器说明。实际通用设置验证布局选项。首登引导依据前端文案，未重新登录触发。 |
| 内置浏览器设置、证书、数据清理和硬件连接 | 验证浏览器设置独立页。翻译证书警告、站点数据和硬件连接提示，保留源站、设备类型和名称。用 DOM 样本核对显示，未接受权限、连接硬件、清理数据或绕过证书。 |
| 语音、远程智能体和权限 | 补充麦克风状态、重连、登录提示、云端权限和 GitHub 仓库入口文案。官方语音与远程智能体有账号和套餐范围，实际通话、认证、远程执行和权限变更留待对应环境验收。 |
| 会话气泡、列表、侧面板、文件和审查 | 核对新版前端仍有会话和转写保护标记。补充差异加载提示，原有正文、代码、文件标识和原生菜单回归继续执行。 |
| 插件导入、账号、MCP、业务修复和性能 | 检查现有插件与技能说明、权限入口及 CDP 与 VS Code 注入链路。上游登录、导入、设备操作、后台任务和性能收益不作为本次实机结论。 |

2.30.0 前端来源为本机原版渲染器的 `main.js`，SHA-256 为 `35e0da21894a7f6560075eae2501c88fede5204eb6067fac2653e2c7a63dc403`。布局选项及说明以本机设置实际显示为准。仅汇总针对本次变更验证的文案，候选匹配不能衡量全产品覆盖率。

## 验证

- 增加 56 条界面文案和 11 条动态规则，覆盖新版首页四种问候语的有名和无名形式，并复用既有正文保护逻辑保留硬件选择器的设备名称。回归先复现 `Settings` 设备名被误译，再验证设备名、站点地址、对话与转写原文保留，以及相邻按钮和无障碍文案正常翻译。
- 两个词库产物、根包和社区插件版本、双语 README 及发版材料与 v3.3.41 对齐。安装器、CDP 及扩展代理继续使用原有链路。
- Windows 2.30.0 桌面与 1.11.0 扩展真实文件副本完成安装、重装、逐字节还原。桌面 347 个外置文件的布局与字节保持一致，765 个打包文件仅 9 个既有补丁目标变化。
- 本机应用两处补丁并核验原版备份。实机复核桌面首页问候语、界面布局与浏览器独立设置页，以及 VS Code Webview 指定中文控件。桌面临时 DOM 样本通过证书警告、源站、硬件选择、语音登录提示及正文保护检查，验证后移除样本。
- 本地 `npm test` 通过，包括 469 条黄金语义断言、31 项既有边界回归、27 项用户内容保护回归和 45 项全局一致性检查。
