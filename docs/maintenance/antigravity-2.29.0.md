## 文件与安装验证

v3.3.34 的真实 2.29.0 安装包副本完成安装与还原，恢复后与原件逐字节相同。本机保留同版本纯净 `app.asar.bak`，指纹为 `7e8a54d474da2969`。

对本机安装结果与该原版备份复核：736 个未修改的 packed 文件内容一致，9 个改变文件均属于预期的菜单/preload/弹窗补丁目标，没有额外改变文件；此前已逐文件核验 347 个 unpacked 文件内容及标记保持一致。

这证明已检查文件的内容保留范围，不代表所有上游功能或平台已验收。获得用户正常退出与重启授权后，本次应用 v3.3.37 补充版本，安装器再次逐文件核验 347 个外置文件并保留纯净备份。最终由用户确认正常退出后重新安装完整词库，通过项目 CLI 启动并确认进程运行；提取的 preload 内字典与最终源码一致，原版备份指纹不变。仅更新桌面补丁，未同步安装可选社区插件或修改用户的 VS Code 扩展。

## v3.3.37 截图缺口复核

- 原因：新 UI 标题、说明及大小写变体未进入词库；连接器启用数量和单个工具计数缺少规则。`Download Location` 在生产翻译引擎中返回 `null`，新增黄金语义用例已先复现失败，再修复通过。
- 补充 27 个界面词条、3 个快捷键标签模板及 5 条有首尾锚点的规则（3 条连接器计数、2 条本地环境/工作树说明）。快捷键标签只组合已知词库操作名与模板；保留按键组合，未知扩展操作名保持原样。动态标签也先复现失败，再加入修复及负例。
- 实机确认通用设置中的下载、浏览历史、浏览器子智能体、语音标题/说明/设备状态，快捷键页中的侧面板和语音操作，以及项目与项目外会话的两处说明。
- 实机确认首页语音按钮标签、工作树菜单两处说明，以及连接器弹层的标题、搜索占位符、会话启用数量、单个工具计数和浏览入口。只查看弹层，未启用或禁用连接器；查看工作树菜单后恢复原先的项目选择。
- 第三方技能描述、技能标识、仓库/会话名称、连接器品牌和文件路径按其内容来源保留，不将任意扩展内容计入本轮官方 UI 漏翻修复。
- 环境菜单的动态说明在本轮末尾发现并补充，保留插入的文件夹列表。电脑控制工具在连接重建和初始化时仍返回中止，因此停止该控制路线；用户正常退出后，最终补丁已通过 CLI 应用并启动。两条环境说明通过生产引擎语义断言，快捷键标签另有 DOM 属性自动化验证；这些附加内容尚未完成最后一次重启后的实机复核，不能写为已实机确认。
- 这些观察与自动化断言对应上述界面和模板；未执行整个上游产品的全量实机遍历，也未验证语音、云端执行等业务功能。

- 根包、社区插件与编译包采用同一项目版本；静态门禁检查三者，检查分层源码与两个导出词库的语义一致性。
