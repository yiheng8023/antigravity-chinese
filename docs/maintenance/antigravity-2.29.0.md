对本机安装结果与该原版备份复核：736 个未修改的 packed 文件内容一致，9 个改变文件均属于预期的菜单/preload/弹窗补丁目标，没有额外改变文件；此前已逐文件核验 347 个 unpacked 文件内容及标记保持一致。

这证明已检查文件的内容保留范围，不代表所有上游功能或平台已验收。获得用户正常退出与重启授权后，已应用本机补充版本并重启，当前为 v3.3.36 词库；嵌入字典与发布源码一致，纯净备份指纹和 347 个外置文件保持不变。实机已核查自动化空状态与外观页新增文案，客户端已返回首页。

## 一致性与文档

- 根包、社区插件与编译包采用同一项目版本；静态门禁检查三者，检查分层源码与两个导出词库的语义一致性。
- 负例覆盖两个导出文件同时偏移、编译版本陈旧、中英文测试数量错误，避免仅凭产物相互一致误报通过。
- 漂移工具缺少有效 bundle 时失败，无候选时覆盖率为未知；技能目录未读到描述时不再报告完整覆盖。测试可写独立报告路径。
- 本次未取得可核验的完整前端 bundle，没有执行真实全量漂移扫描；不提供整个产品的翻译覆盖率。
- 双语 README 改为当前组件支持和验证范围，取消无范围的就绪/覆盖承诺；保留赞助与社区资产。贡献指南、AGENTS、诊断技能和 CLI 统一社区项目身份及维护流程。
