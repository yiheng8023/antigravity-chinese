# v3.3.46 自定义扩展内容边界

2026-11-12，用户补充说明，截图只展示部分内容，项目内和未归属项目的技能、规则和插件应一致处理，单处适用的词条也不应自动覆盖全局。

## 显示原则

| 来源与位置 | 处理 |
| --- | --- |
| 客户端栏目、操作、固定状态与设置说明 | 按该位置的语义汉化 |
| 技能、规则、插件和自定义智能体的名称、作者说明 | 保留原文，覆盖内置与用户安装的资源 |
| 插件来源、工作区名称、作者、版本、事件标识和建议提示词 | 保留原文 |
| 消息、文件、代码、网址与项目/会话名称 | 延续已有内容保护 |

例如 `Settings` 用于设置按钮时可显示“设置”，用于资源名称或说明时仍显示 `Settings`。原内容是中文或中英混合时也保持原样。`dict/src/ctx/` 的分目录只组织源文件，编译后会合并，运行时的边界才决定词条能在哪些位置生效。
