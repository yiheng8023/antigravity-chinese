# Antigravity App 2.35.0 桌面适配

2026-11-24 核对到本机 Windows x64 桌面应用和 ASAR 均为 2.35.0。Google 于 2026-11-23 发布此版，包含会话保留与管理、环境选择器、权限、排队消息、产物检索及文件文字方向的变化。上游灰度功能以实际可见入口为准。[Google 更新日志](https://antigravity.google/docs/changelog/)

原版 ASAR 的 SHA-256 为 `99ff7f6cf1219f46c8437df65ca866e384836b5230adba8efd91b3152f823e15`。官方语言服务器内嵌的 `main.js` 为 12,798,818 字节，SHA-256 为 `f039eca519f153aeac9a0f1d10abc7afd8ff4b8009ef78d684669a3c7955f54d`。更新后的原包由安装器在首次应用补丁时单独备份。

| 变化 | 汉化处理 |
| --- | --- |
| 会话历史与管理 API | 会话归档操作复用已有译文。会话标题、数据、API 标识及保留行为由原客户端处理。 |

| 权限和模型选择锁定 | 补齐智能体运行期间的固定提示和权限选择器读屏文案。模型名、权限值、沙箱策略与用户设置沿用原客户端行为。 |
| 排队消息与后台任务 | 汉化固定提示及排队状态的前缀。等待对象的名称、任务名和消息正文保留原文。 |
| 文件与 HTML 产物 | 补译纯文本和 Markdown 的文字方向按钮。检索沿用已有标签、匹配计数与查找入口。文件内容与 HTML 产物自身由原渲染器显示。 |
| 插件市场、Swarm 和云端入口 | 插件简介继续按来源、插件 ID 与完整原文匹配。已有译文出现在匹配的面板，新内容或不匹配的第三方文案保留原文。会话 API、云端许可证、权限执行和远程克隆的行为未纳入测试。 |

## 验收反馈修订

- 上游把多处设置项标题改为句首大写，例如 `Prevent sleep` 和 `Font size`。源包确认新写法后，补充精确词条并复用原译文，保留旧版标题的兼容性。另核对了环境菜单的本机和云端固定说明。
- 「模型与用量」将套餐前缀和名称作为相邻文本，「账户」将它们组成一段文案。两个页面共用 `Your plan` 的设置内翻译规则，实机抽查的 Google AI Pro 套餐名按原文显示。
- 在 Antigravity 官方目录和其安装记录中核实了 Gemini API 加入 Genie 4 和音乐生成的完整介绍。新旧原文分别按同一插件 ID、官方来源和全文匹配。项目设置和未归属会话均有同名本地插件保留英文的负例。
- Windows x64 上用首轮补丁复现了六个设置页的英文残留和四处 Gemini API 官方简介的英文显示。应用修订后，实机核对了环境菜单的本机说明、六个设置页共 19 处标注，以及插件市场、已安装、详情和未归属会话设置中的 Gemini API 简介。项目设置的插件简介另由 DOM 回归覆盖。
- 修订后 `npm test` 和源包文案审计通过。用首轮补丁副本验证了覆盖安装、重复安装和原版还原，377 个外置文件的路径和内容哈希一致。本机修订补丁与副本的 SHA-256 一致，为 `604c63031df4f57fe474ec6be636d659f6a355af7430d46f8a16be7d35234d10`。纯净备份仍可核对至官方原包。
