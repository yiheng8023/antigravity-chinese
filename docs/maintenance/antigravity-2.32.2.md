# v3.3.50：Antigravity 2.32.2 与设置性能修复合并维护

## 来源与上游变化

2026-11-17，用户在性能修复待发布时更新桌面到 2.32.2，因此暂缓创建标签和 Release，先按新版本检查。再次核查[官方更新日志](https://antigravity.google/docs/changelog/)，桌面仍列到 2026-11-13 的 2.32.0，搜索未找到官方 2.32.2 说明。以下版本结论来自本机安装包与运行界面，不虚构官方变更内容。

- Windows x64 安装包版本：2.32.2；纯净 ASAR SHA-256：`056ba838faf9b75c1382a6a0ae003c4b051a3c3e50060a9e5b34987313492d77`。
- 实际运行页面的 `main.js` 为 12061895 字节，SHA-256：`4c0a1ff5659e7dd92e6ad249a386c0dbce2c8e94b88522a2f366ff20b397081e`，与 2.32.1 的已审查脚本完全一致。1052 条 UI 文案与 45 项保留/组合决定通过哈希及文本存在校验；保留原清单的来源版本，仅补充同源验证记录，没有替换哈希冒充重新提取。
- 内置 Swarm 的 `index.html`、`app.js`、`hive.js`、`main.mjs` 与[上一轮记录](swarm-pane-2.32.1.md)的哈希一致；独立 frame 来源边界及限定词库继续适用。
- ASAR 仍有 721 个打包文件、347 个外置文件。原生菜单、托盘、更新和 WSL 提示的入口继续存在；补齐一条先前遗漏的 WSL 发行版缺失说明，保留 `${WSL_DISTRO}` 插值。该错误路径以安装包与集成回归验证，没有触发实际 WSL 故障。
- VS Code 扩展仍为 1.12.0，桌面上游更新没有据此被解读为 IDE 同时更新。共享运行时的性能修复已交付到该扩展的 Webview bundle。

## 安装、备份与内容保护

官方更新覆盖了桌面补丁，并移除了旧版目录中的 `.bak`。在任何本轮写入前，把 2.32.2 纯净 ASAR 复制到任务目录并校验哈希；不把旧 2.32.1 备份重建到新版路径。真实安装包副本完成安装、重复安装与还原：重复安装字节一致，还原字节与 2.32.2 纯净输入一致。347 个外置文件的布局和内容保持。

本机客户端正常退出后安装修复，首次生成的新版备份与上述 2.32.2 纯净哈希一致。主前端、Swarm 来源和词库无需新增映射，继续使用按内容来源与控件位置限定的翻译；项目内和未归属项目的名称、描述、提示词、任务和消息均保留作者原文。

性能修复见[2.32.1 专项记录](settings-performance-2.32.1.md)。仅在一个同步片段内缓存判断，异步任务按 6 ms 软预算和最多 200 个节点推进，超过 500 个待处理根时合并而不丢尾部。此修复没有放宽作者内容保护，也没有删除用户缓存或采用其他汉化器。

## 新版实机采样

采样数据独立保存在 [`settings-performance-2.32.2.json`](../../test/fixtures/settings-performance-2.32.2.json)，不把 2.32.1 的性能结果当作新版本验收。

| 2.32.2 对应采样 | 英文原版 | 修复版首次采样 | 修复版后续热态采样 |
| --- | ---: | ---: | ---: |
| 打开设置最大帧间隔 | 130.1 ms | 250.0 ms | 113.4 ms |
| 关闭设置最大帧间隔 | 33.4 ms | 63.4 ms | 60.0 ms |

这些是同机少量样本，首次加载与热态不能混为同一条件。新版本首次采样仍有长任务，也没有在 2.32.2 上重新安装 3.3.49 作旧版对照，因此不声称所有开关操作都与英文原版相同或达到固定 FPS。性能缺陷的因果回归、热扫描对照与原版宿主开销分别记录，避免以功能通过代替性能结论。

另一次热态开关的 V8 栈采样总窗口约 1491 ms，其中约 55 ms 的采样栈包含已识别的汉化函数。它只用于进一步区分运行时工作和宿主成本，不是最大帧间隔的完整归因，也不证明剩余长任务与汉化无关。Profiler 与临时计数器随后关闭。

2.32.2 实际界面中依次访问通用、应用设置、外观、快捷键、通知、模型配置、浏览器七个入口，确认中文导航及基本开关操作；独立 Swarm frame 自动显示“此会话尚无 Swarm”。未启动真实 Swarm 或云端任务。实际安装的 2.32.2 preload 提取汉化脚本后，42 项内容回归和 4 项性能回归全部通过；扩展 1.12.0 的实际 bundle 也已分别通过同样 46 项检查。
