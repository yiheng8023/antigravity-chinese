# Antigravity 2.29.1 维护记录

2026-11-09 核对 [官方桌面更新日志](https://antigravity.google/docs/changelog/) 和 [官方扩展更新日志](https://antigravity.google/docs/changelog?tab=extensions&ide=vscode)。桌面 2.29.1 发布于 2026-11-06。Windows x64 实测基线为 App 2.29.1、VS Code 1.145.2 及 Antigravity 扩展 1.11.0。桌面自动更新后回到原生 ASAR，VS Code 扩展仍保留 v3.3.39 的汉化运行时。

## 上游变更与汉化影响

| 官方修复 | 影响与验证 |
| --- | --- |
| 语音会话在登录状态过期时提示重新登录 | 核对前端连接回退、登录提示与现有词条。补充无法连接、麦克风不可用、连接中等界面文案。 |
| 语音会话可识别键入的链接与提及 | 汉化补充语音浮层的输入提示与操作。原有输入框、链接引用及用户内容保护回归继续执行。 |
| 避免把上一段发言附到下一段 | 根据前端实际结构保护 `live-user-turn` 与 `live-agent-turn`。回归覆盖实时文本与被分段渲染的回复。 |
| 短暂断线后的转写与已听到的回复一致 | 保护历史转写的 `transcript-line-text`，同时翻译转写卡片、连接状态和无障碍标签。 |

从本机 2.29.1 渲染器读取的 `main.js` 提取语音控件、动态语速与计时格式、正文容器。源文件 SHA-256 为 `eec7297695f3b4f25d4e92f5f9d0bc4efeec86523cddcddddefc3410c5efe37a`。此次按变更范围核对前端，不把候选文本匹配当作全量翻译覆盖率。

## 实施与验证

- 补充 19 条语音界面文案和 3 条带边界的动态规则。转写保护复用 v3.3.39 的正文边界与节点观察流程，保留原始文本、属性与分段节点。
- 先复现旧运行时把 `Settings` 转写成“设置”，再验证实时转写、分段回复和历史转写保留原文，而同页面的按钮和错误提示继续翻译。
- 桌面 2.29.1 与 VS Code 扩展 1.11.0 的真实文件副本通过安装、重装及字节一致还原。桌面 347 个外置文件保持字节一致，745 个打包文件中仅 9 个既有补丁目标发生变化。
- 词库源与两种生成产物、根包和插件版本、双语 README 与维护记录同步为 v3.3.40。既有 ASAR 安装还原、CDP 及扩展代理链路由全量回归复核。
- VS Code 扩展仍处于官方 1.11.0 版本。其本地化使用同一运行时。独立 Antigravity IDE 2.6.0 是单独产品，本项目的兼容性结论限于桌面 App 和 VS Code 扩展。
- 本机应用两处补丁。新建的桌面原版备份与更新后的原生 ASAR 哈希相同，扩展原版备份哈希保持一致。桌面实机语音入口显示中文，临时 DOM 样本的错误提示、无障碍标签和转写保护通过。样本已移除，实机检查范围限于界面和临时 DOM，实际录音、重新登录及断线恢复未在本机复验。
- VS Code 1.145.2 的实际扩展 Webview 核对了“新建会话”、输入提示和“添加到上下文”。本地 `npm test` 通过，包括 402 条黄金语义断言、26 项用户内容保护回归和 45 项一致性检查。
