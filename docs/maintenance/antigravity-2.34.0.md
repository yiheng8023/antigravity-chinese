# v3.3.56 适配 Antigravity App 2.34.0

2026-11-21 在 Windows 11 x64 核对到官方安装的桌面程序和 ASAR 均为 2.34.0。官方更新日志将本版列于 11 月 20 日，记录 Gemini 4 Neon、面向符合资格账号的 MCP Apps、输入框发送键和终端旁路提问等变化。本次适配以本机原包和已校验的上一版前端为依据。[Antigravity 官方更新日志](https://antigravity.google/docs/changelog/)

本机原版 ASAR 的 SHA-256 为 `8934adef0622c9271c92eea950a71848764a66f7b10023ccbd82e54b959adb0e`。从官方安装的语言服务器提取的前端 `main.js` 为 12,581,273 字节，SHA-256 为 `d52ce739c15044c02a32e1b9df62bfe39dd8164c70a2ab783540e6ed5e070251`。使用 [2.33.0 前端](antigravity-2.33.0.md) 的已确认哈希作为对照，与本机上一版 2.33.1 的前端相同。

从实际前端复核了 [95 项 UI 字面量和 11 项保留或限定处理决定](../../test/fixtures/app-2.34.0-ui.json)。动态倒计时、请求内容边界和 MCP Apps 状态前缀由 DOM 回归覆盖。设置扫描预算沿用既有配置，通过内容保护与性能回归。

在本机原包副本验证了首次安装、重复安装和还原。两次补丁字节一致，原版备份、还原后 ASAR 和 377 个外置文件均通过哈希校验。补丁仅改动 9 个打包文件，改动的 JavaScript 均通过语法检查。

本机已安装的 ASAR 与副本验收结果一致。独立配置启动的登录页显示「欢迎使用 Antigravity！」。通过现有配置打开通用设置，确认「输入框」和发送快捷键说明显示中文。测试窗口和临时调试监听均已关闭。

当前配置未显示新版侧栏入口，相关文案以源码核对和 DOM 回归为证据。MCP Apps 的实际插件调用、模型灰度、浏览器实时查看和录音未实测。macOS 和 Linux 的本轮范围为跨平台自动化。

本机 VS Code 扩展仍为 1.13.0，安装的 v3.3.54 补丁仍可识别。扩展的包和 UI 适配见 [2.33.1 维护记录](antigravity-2.33.1.md)。
