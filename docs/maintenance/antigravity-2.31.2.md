# Antigravity 2.31.2 与 VS Code 扩展 1.12.0 维护记录

2026-11-12 核对本机 Windows x64 上的 App 2.31.2、VS Code 1.146.0 和 Antigravity 扩展 1.12.0。两个组件的旧汉化均已被上游更新覆盖。

## 官方来源与实际版本

[官方桌面更新日志](https://antigravity.google/docs/changelog/) 当前仍以 2026-11-09 的 2.31.0 为最新桌面条目，现列出 10 项改进和 18 项修复，尚未单列 2.31.2。安装包版本与实机前端均已核对，2.31.2 的补丁级上游改动范围保留为未知。

实际运行的 2.31.2 前端 `main.js` SHA-256 为 `00c7aa77bcd1f0bce710f98a97be1e10c0b0fe91770d79216c94b47f2e591308`，与上次核验的 2.31.0 相同，沿用已有下载审批、语音摘要、云项目和自定义扩展词库及内容保护。桌面 ASAR 的 SHA-256 为 `94452cf0ce71bb4c21cfbdd51b31c0c6404e7aeb99539bdecce8954175b9dbaf`。

[官方 VS Code 扩展日志](https://antigravity.google/docs/changelog?tab=extensions&ide=vscode) 的 1.12.0 条目发布于 2026-11-09，含 7 项改进和 5 项修复。本机扩展自带的 `CHANGELOG.md` 指向该页面。原版 `extension.js` SHA-256 为 `d5299addfab2ab4ad0b08e1e4c3a403190d35cdfd5cbb2e2ae51cf38c0070210`。

## 变更影响

| 上游范围 | 处理与验证边界 |
| --- | --- |
| 后台快速启动、60 秒启动就绪等待与后台更新 | 核对原生进度和更新提示，补齐已确认的显示文案。版本号、启动超时默认值、更新调度和实际启动逻辑沿用上游实现。 |
| 远程登录端口转发与授权码回退 | 补齐登录卡片、等待授权和登录成功提示，保留授权参数与流程。远程主机认证需对应环境验证。 |
| 企业代理与 CA 证书 | 补齐 PEM CA 文件设置说明及更改配置后的重载提示，保留证书路径、设置值和信任行为。未安装证书或调整代理。 |
| 会话搜索快捷键与无障碍消息导航 | 核对命令清单和 Webview 注入入口，保留按键及内容语义。 |
| Windows 退出恢复、共享频道二进制、元数据与通知窗口修复 | 保留上游业务实现。中文通知按钮映射回原操作值，避免影响重载、审查或反馈处理。跨窗口、系统注销和上游恢复收益需独立验证。 |

本版增加 35 条精确文案与 4 条动态规则，并将扩展静态显示字段、进度和状态提示纳入已有注入流程。补齐前端实际轮换使用的三组问候语及其无用户名形式，项目选择规则保留实际项目名。对已识别的原生通知使用中文 MessageItem 展示操作，回传上游原操作字符串。保留取消、原选项对象、动态消息和动态内容，更新通知只翻译已识别的版本提示。

## 验证结果与限制

- `npm test` 全部通过，包含 507 项界面文案断言、36 项 ASAR 生命周期检查、32 项综合回归、29 项用户内容回归和 45 项全局一致性检查。
- 对 Windows x64 的 App 2.31.2 和扩展 1.12.0 安装包副本完成安装、重复安装和字节一致还原。桌面 765 个包内文件中仅 9 个既有目标文件变化，347 个外置文件保持原样，全局插件隔离标记完整保留。
- 扩展保留全部 31 个命令 ID、12 个设置的默认值和原始备份，启动就绪等待仍为上游的 60 秒。新增通知回归核对中文消息、操作返回值、原选项对象、取消、错误、动态内容和字节一致还原。
- 依赖核查发现本机安装版本与项目声明不一致，重新按现有声明安装 ASAR 3.2.14 和 jsdom 22.1.0 后执行验证。
- 实机在 VS Code 1.146.0 加载扩展 1.12.0，核对原生中文菜单及 Webview 显示。标题栏辅助标签 `More Actions...` 位于 VS Code 本体的语言资源中，扩展原版脚本未包含此文案。本机微软中文语言包安装入口回报已安装，仍保留这一处本体侧漏译。
- 本机安装后正常启动桌面 2.31.2 与扩展 1.12.0，复核中文问候语、公告区域、项目选择和输入提示。IDE 验收窗口已正常关闭，桌面客户端正常运行。当时收到 Computer Use 完成回执，随后用户反馈黄框仍存在，实际释放的补充处理见 [v3.3.45 记录](antigravity-2.31.2-follow-up.md)。实际登录、证书信任、重启后台、权限审批和远程任务不属于本次业务验收。
