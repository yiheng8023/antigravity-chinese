# Antigravity 2.31.0 维护记录

2026-11-11 核对 [官方桌面更新日志](https://antigravity.google/docs/changelog/) 与 [VS Code 扩展更新日志](https://antigravity.google/docs/changelog?tab=extensions&ide=vscode)。官方桌面 2.31.0 条目日期为 2026-11-09，列出 11 项改进与 18 项修复。Windows x64 本机为 App 2.31.0、VS Code 1.145.2 和 Antigravity 扩展 1.11.0。桌面更新覆盖了旧汉化，扩展仍保有既有补丁。

本机原版 2.31.0 渲染器的 `main.js` SHA-256 为 `00c7aa77bcd1f0bce710f98a97be1e10c0b0fe91770d79216c94b47f2e591308`。本版增加 26 条界面文案与 3 条下载范围规则。旧运行时会将下载详情中的 `Settings` 改为“设置”，回归验证修复后仅翻译标签和操作。语音摘要及项目建议使用实际前端的内容标记验证。词库、两种生成产物、根包和社区插件版本、双语 README 同步为 v3.3.43。

## 指定路径还原的隔离修复

新版副本检查发现旧 CLI 在执行 `restore --path` 时，也会卸载默认全局中文插件。现在只有默认还原流程会卸载全局插件。隔离回归使用临时插件目录，先复现该目录被错误删除，再检查自定义路径还原及上游更新清理后插件文件仍保持原样。ASAR 打包与备份、CDP 和 VS Code 代理继续使用既有链路。

- `npm test` 全部通过，包含 498 项界面文案断言、36 项 ASAR 生命周期检查、29 项用户内容回归和 45 项全局一致性检查。
- Windows x64 上对 App 2.31.0 和 Antigravity 扩展 1.11.0 安装包副本验证安装、重复安装与还原。核对注入的运行时与新增译文，桌面原版与 347 个外置文件的 SHA-256 校验一致，扩展的原始文件校验一致，隔离用的插件标记文件完整保留。
